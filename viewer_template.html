How to read the case code (the letters in a docket number)

Every docket number has three parts: the utility ID, the case code, and the case number. For example, 6680-UR-124 is utility 6680 (Wisconsin Power and Light Company), case code UR (combined utility rates), case number 124. Most codes are two letters; a few are one or three (CPF and PGA, for instance). Click a code in the table to filter the list to that case type.
